# Основа — математический практикум

Статический каталог задач: сборка на **Python**, формулы KaTeX, поиск и фильтры, маршрут обучения и сохранение прогресса в браузере.

## Запуск локально

Нужен Python 3.10+. В папке проекта выполните:

```sh
python3 run.py
```

Откройте **http://localhost:8000**. Остановить: **Ctrl+C**. Другой порт: `python3 run.py --port 8080`.

После изменения задач или оформления выполните `python3 build.py` и обновите страницу.

## Где index.html

- **`index.html` в корне** — вход, открывающий собранный сайт.
- **`dist/index.html`** — готовая страница после `python3 build.py`.
- **`templates/index.html`** — исходный шаблон для редактирования.

Для сохранения прогресса открывайте сайт через локальный сервер, а не через `file://`.

## GitHub Pages

В репозитории: **Settings → Pages → Source → GitHub Actions**. Push в `master` запускает `.github/workflows/pages.yml`: Python собирает сайт, а Pages публикует содержимое `dist/`, где `index.html` находится прямо в корне публикации.

Адрес сайта: **https://jollu8.github.io/math-ptractices/**. Публикация выполняется после push и включения Pages.

## Как расширять

- Задачи: `content/problems/` — отдельный JSON на задачу; можно создавать подпапки по темам.
- Порядок обучения и стартовая задача каждой темы: `content/roadmap.json`. Сборка проверяет, что все темы каталога включены в маршрут, а ссылки ведут на задачи нужной темы.
- Шаблон задачи: `examples/problem.template.json`; схема: `content/problem.schema.json`.
- Название сайта, автор, ссылки, кнопка кофе и уровни: **`content/site.json`**.
- Оформление: `assets/style.css`; поведение: `assets/app.js`.
- PDF: `public/materials/`.
- [Подробности формата и наполнения](docs/content-guide.md).

Прогресс сохраняет последнюю задачу, решённые задачи, раскрытые блоки и фильтры в `localStorage`. Он доступен в том же браузере и по тому же адресу; стабильные `id` задач сохраняют его при добавлении новых материалов. Между устройствами синхронизации нет.

Кнопка **«Кофе автору»** пока открывает Telegram автора. Для донатов замените `coffee_url` в `content/site.json`.

Проверки: `python3 scripts/check.py`; проверка интерфейса и поведения — `node --check assets/app.js && node scripts/check-ui.cjs`. GitHub Actions запускает эти проверки для pull request и перед публикацией изменений из `master`.
